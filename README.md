# mathquiz

Current status:

This application was made with claude.io, because I needed a quick way to teach my kid basic math multiplication. Basically I was tired of answering qustions in the form of "what is x * y ?". Maybe later I'll come around to expand it with addition, divison and other things. But for now, it works by asking the user what x times y is, where x and y is random selected numbers from 1 to 10.

## build mathquiz

go build mathquiz.go

## run mathquiz

./mathquiz
